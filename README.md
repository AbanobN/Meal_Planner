# Meal Planner (Android, Java)

An Android app to plan daily meals and track nutrition, built in **Java** with **Room Database** and **MVP architecture**.

## 🍽️ Features
- Add / edit / delete meal plans  
- Persist data with Room (SQLite)  
- Filter by category & calories  
- Simple daily dashboard

## 🧰 Tech Stack
Java • Android SDK • Room • RecyclerView • MVP

## ⚙️ Architecture
- **Model**: Room entities & DAOs  
- **Presenter**: business logic  
- **View**: Activities/Fragments (UI)

## 📚 What I Learned
- Applying MVP on Android  
- Local storage with Room  
- Lifecycle-aware UI updates
